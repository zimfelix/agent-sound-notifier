# Ideas — optional planning memory

Use an idea for an unresolved choice or a genuinely multi-session plan. A clear direct request is already authorization; no second approval ritual. Record scope, alternatives/decision, linked specs, remaining tasks and next step. Do not duplicate acceptance criteria or test evidence.

Suggested statuses: Open, Authorized, Deferred, Done, Rejected. Deferred/Open ideas are not implementation requests. Archive only when it helps navigation. For a straightforward change the request plus active spec is enough.
